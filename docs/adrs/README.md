# Registro de Decisões de Arquitetura (ADRs)

Cada decisão relevante é registrada em um arquivo `ADR-NNNN-titulo.md`, com as seções:
Contexto, Decisão, Alternativas consideradas, Consequências e Questões em aberto.
Uma ADR aceita não é editada em seu mérito; se a decisão mudar, cria-se uma nova ADR que a
substitui (status "Substituída por ADR-XXXX").
